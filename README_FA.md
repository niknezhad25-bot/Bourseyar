# بورس‌یار — نسخه آغازین اندروید

این پوشه یک اسکلت اولیه Android Studio با Kotlin و Jetpack Compose است.

## امکانات فعلی
- رابط فارسی و راست‌چین
- تم سرمه‌ای و سبز
- فهرست پنج نماد: فملی، وبملت، شستا، آریا و فنقره
- صفحه اولیه داشبورد و جایگاه گزارش اخبار/تحلیل
- نمایش صریح اینکه قیمت‌ها هنوز به منبع زنده متصل نیستند

## هنوز پیاده‌سازی نشده
- اتصال و اعتبارسنجی شناسه‌های دقیق نمادها در TSETMC
- دریافت قیمت و معاملات با کمترین تأخیر ممکن
- سرویس ابری و پایگاه داده
- جمع‌آوری خبر، حذف خبر تکراری و تحلیل اثر خبر
- اعلان Push اندروید و آرشیو پایدار
- ساخت و امضای APK نهایی

## باز کردن پروژه
1. Android Studio را نصب کنید.
2. از مسیر File > Open، همین پوشه را انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود.
4. یک شبیه‌ساز یا گوشی اندرویدی متصل کنید و Run را بزنید.

## معماری پیشنهادی نسخه کامل
Android App → HTTPS Backend → TSETMC / منابع خبری معتبر → پایگاه داده
Backend → اعلان Push (Firebase Cloud Messaging)

نکته: مستندات REST جدید TSETMC در https://api.tsetmc.com/docs/ معرفی شده است.
قبل از نمایش هر داده به‌عنوان «زنده»، باید دسترسی، مجوز استفاده، دقت و تأخیر داده‌ها برای هر پنج نماد آزمایش شود.
